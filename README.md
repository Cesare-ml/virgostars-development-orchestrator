# VirgoStars Development Orchestrator

An experimental coordination layer for human and AI contributors working across VirgoStars repositories.

This repository is being bootstrapped. Work is proposed in feature branches and reviewed through pull requests; no orchestrator service is deployed and no automatic GitHub merges or deployments are enabled.

## Repository ownership migration

See the [GitHub Organization repository transfer checklist](docs/GITHUB_ORGANIZATION_REPOSITORY_TRANSFER.md) for owner-controlled verification of the destination organization, repository identities and GitHub App permissions. This process is separate from the private coordination-ledger cutover and authorizes no transfers or agent writes.
